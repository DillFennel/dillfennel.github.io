Яндекс Go Payments

Стажёр-разработчик бэкенда

C++ · Python · userver

Способы оплаты, погашение долгов и мониторинг платежей.

  • Подключение способов оплаты через конфигурацию. Реализовала добавление новых типов поддерживаемого формата без отдельных изменений кода под каждый тип. Расширила API и проверила совместимость и полный сценарий на тестовом окружении.
  • Общая C++-библиотека способов оплаты. Унифицировала правила смены метода, отделила общую доступность от возможности оформить заказ. Добавила серверные проверки и сравнивала новую логику со старой в режиме dry-run.
  • API погашения долгов. Перенесла расчёт списка долгов для выбранного способа оплаты на сервер. Сохранила совместимость со старыми клиентами и ограничила число запросов к зависимым сервисам.
  • Наблюдаемость платежей. Переработала дашборды платежей, долгов, чаевых и верификаций для двух контуров. Реализовала базовый сбор метрик отдельных транзакций и позиций счёта; ошибки сбора не прерывают обработку платежа.
  • Бот сводок по инцидентам с LLM. Разработала отбор платёжных инцидентов, подготовку сводок для продуктовых менеджеров, обновление карточек и защиту от повторных отправок. Развернула бота в тестовом окружении.

Стажёр-разработчик C++ · Инфраструктура Новой БК

Инфраструктурные компоненты рекламного движка.

  • Перенос инфраструктурного компонента на C++. Переписала компонент Rooster; изменения влиты в основную кодовую базу.
  • Корректная проверка новых версий. Исправила выбор stable/prestable при обращении к нескольким шардам: в рамках одного вызова используется одно окружение, без смешивания стабильной и тестируемой версий.
  • Упрощение архитектуры кешей. Участвовала в переходе RTB-cache и cache-proxy к одному стейджу без proxy-слоя: подготовила переключение запросов и эксперимент, удалила завершённую экспериментальную логику.
  • Развёртывание и сопровождение. Подготовила Infractl-конфигурации для кешей и Metronome, добавила XGen в Metronome и удалила устаревшие конфигурации деплоя.
  • Метрики и проверки. Добавила HTTP/HTTPS-метрики и тесты инфраструктурного компонента. Перенесла метаданные тегов в protobuf extensions и расширила проверки новых тегов.
